# v0.1.0

First qualified Linux release of StackChan MCP.

- Single binary for the XiaoZhi WebSocket bridge and MCP stdio server.
- Linear ticket discovery, project resolution, and isolated ticket work sessions.
- Updated dependencies and patched Go 1.26.10 build baseline.
- Linux amd64 and arm64 archives with SHA-256 checksums.

Runtime prerequisites: Linux, Secret Service with `secret-tool`, and the documented
CLI tools for ticket work (`git`, `tmux`, and Codex). Configure service credentials
locally with `stackchan-mcp setup`; credentials are not included in the release.
